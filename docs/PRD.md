# 여행 가이드 블로그 - PRD (Product Requirements Document)

## 1. 프로젝트 개요

### 프로젝트명
여행 가이드 블로그

### 목적
Notion을 CMS(Content Management System)로 활용하여 관리하는 개인 블로그 웹사이트를 구축합니다. Notion 데이터베이스에서 글을 작성하면 자동으로 블로그에 반영되는 방식으로 콘텐츠 관리의 효율성을 높입니다.

### 핵심 가치
- **쉬운 콘텐츠 관리**: Notion의 직관적인 UI에서 글을 작성하기만 하면 블로그에 자동 반영
- **비용 효율성**: 별도의 백엔드 CMS 없이 Notion API를 활용
- **빠른 배포**: Next.js 기반의 정적/동적 하이브리드 생성으로 빠른 로딩 속도 제공

### CMS 선택 이유
- Notion은 이미 많은 사용자가 노트 작성에 활용하고 있어 러닝 커브가 낮음
- Notion API를 통해 체계적인 데이터 관리 가능
- 복잡한 백엔드 구축 없이 API 연동만으로 CMS 기능 구현

## 2. 주요 기능

### 2.1 Notion 데이터베이스 연동
- Notion API를 통해 데이터베이스의 글 목록 실시간 조회
- 자동 캐싱을 통한 성능 최적화
- 발행 상태(초안/발행됨)에 따른 필터링

### 2.2 카테고리별 필터링
- 등록된 카테고리별로 글 분류 표시
- 동적 카테고리 페이지 생성
- 선택된 카테고리의 글 개수 표시

### 2.3 검색 기능
- 제목 및 태그를 기반으로 한 검색
- 실시간 검색 결과 필터링
- 검색어 강조 표시

## 4. Notion 데이터베이스 구조

### 필드 정의

| 필드명 | 타입 | 설명 | 필수여부 |
|-------|------|------|--------|
| **Title** | Title | 블로그 글의 제목 | ✓ 필수 |
| **Category** | Select | 글의 카테고리 (예: 아시아, 유럽, 남미 등) | ✓ 필수 |
| **Tags** | Multi Select | 글과 관련된 태그들 (여행지, 경험 등) | - |
| **Published** | Date | 글 발행 날짜 | ✓ 필수 |
| **Status** | Select | 글의 상태 (초안/발행됨) | ✓ 필수 |
| **Content** | Page Content | 블로그 글의 본문 내용 | ✓ 필수 |

### Status 옵션
- **초안 (Draft)**: 작성 중인 글 (블로그에 미표시)
- **발행됨 (Published)**: 발행된 글 (블로그에 표시)

## 5. 화면 구성

### 5.1 홈 페이지 (`/`)
- **역할**: 가장 최근에 발행된 글들을 목록 형태로 표시
- **구성요소**:
  - 헤더 (제목, 설명)
  - 글 카드 목록 (썸네일, 제목, 카테고리, 발행일, 요약)
  - 페이지네이션 또는 "더보기" 버튼
  - 사이드바 (인기 카테고리, 태그 클라우드)

### 5.2 글 상세 페이지 (`/posts/[slug]`)
- **역할**: 개별 글의 전체 내용을 표시
- **구성요소**:
  - 글 제목, 카테고리, 발행일, 작성자 정보
  - 내용 본문 (Notion 블록 렌더링)
  - 태그 목록
  - 관련 글 추천
  - 이전/다음 글 네비게이션

### 5.3 카테고리 페이지 (`/categories/[category]`)
- **역할**: 특정 카테고리에 속하는 모든 글을 표시
- **구성요소**:
  - 카테고리 제목
  - 해당 카테고리의 글 목록
  - 필터 옵션 (정렬: 최신순, 제목순)
  - 글의 개수 표시

### 5.4 검색 결과 페이지 (`/search`)
- **역할**: 검색어에 맞는 글을 찾아 표시
- **구성요소**:
  - 검색 바
  - 검색 결과 목록
  - 검색된 글의 개수 표시
  - 결과 없음 메시지

## 8. 성공 기준

### 기술적 성공 기준
- Notion API 연동 성공 (데이터 조회 정상 작동)
- 모든 글에 대해 동적 페이지 생성 성공
- 페이지 로딩 속도 3초 이내 (LCP)
- 모바일 반응형 100% 준수

### 비즈니스 성공 기준
- Notion에서 글 작성 후 자동으로 블로그에 반영
- 사용자는 별도의 배포 없이 Notion만으로 콘텐츠 관리 가능
- 초기 10개 이상의 여행 가이드 글 등재

## 9. 개발 환경 및 준비사항

### 필수 준비물
1. **Notion 계정 및 데이터베이스**
   - Notion 데이터베이스 생성
   - API 통합(Integration) 생성 및 시크릿 키 발급

2. **개발 환경**
   - Node.js 18.17.0 이상
   - npm 또는 yarn 패키지 관리자

3. **환경 변수 (.env.local)**
   ```
   NOTION_API_KEY=your_notion_api_key
   NOTION_DATABASE_ID=your_database_id
   ```

### 초기 콘텐츠
- 테스트용 샘플 글 최소 3개 이상
- 카테고리 최소 3개 설정 (예: 아시아, 유럽, 남미)

## 11. 문제 해결 및 고려사항

### 예상 이슈
1. **Notion API 레이트 제한**: 호출 횟수 제한에 따른 캐싱 전략 필요
2. **블록 렌더링**: 복잡한 Notion 블록 타입에 대한 처리
3. **이미지 최적화**: Notion 이미지의 최적화 및 로딩 속도

### 해결 방안
- ISR(Incremental Static Regeneration) 활용
- 외부 라이브러리 활용 (react-notion-x 또는 유사 라이브러리)
- Next.js Image 컴포넌트로 최적화
